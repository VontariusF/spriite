Why setup changes

Your Factory computer already knows your keys. Let it hand them over.

Today

13 steps · 4 places
TerminalClone, install, deploy the relay, pack
Even HubCreate a project, upload, install
HostKeep a Droid Computer online, run the broker installer
PhoneFactory key, then GitHub or Cursor key just to pick a repo, then voice, X token JSON, archive key, about 30 Factory-native fields
What hurts
The required repo step is blocked by keys marked optional.
The Factory key, repo and models are each entered two or three times.
Host output gets copied into the phone by hand.
The Factory-native form sits on the Now tab, full of protocol words.
A new phone means doing all of it again.

Proposed

3 steps · 1 command
1
Install Spriite on the glassesFrom Even Hub. Self-hosters still bring their own relay at build time.
2
Pair with your Factory computernpx spriite pairReads the Factory login, GitHub CLI, Droid computer and host link. Shows a short code. You type the code on the phone and everything comes over encrypted.
3
Choose where builds goA new repo per idea, or one you pick or paste. Never blocked by another key.
What changes
No secret is typed on the phone. Voice and X connect from the computer too.
One home screen: glasses mirror, one composer, what needs you.
Factory-native details move to Settings › Advanced.
Key-only users get the same flow, minus the computer step.
New phone: one transfer code moves keys, defaults and history.
